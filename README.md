Como Trabalhar no Projeto (O Ciclo de Trabalho)
Este é o processo que TODOS devemos seguir para manter tudo organizado e evitar problemas.

A REGRA DE OURO: ATUALIZE ANTES DE TRABALHAR!
Antes de abrir o RPG Maker para fazer qualquer alteração, SEMPRE faça isso:

Abra o GitHub Desktop.

Clique no botão Fetch origin no topo.

Se aparecer um botão dizendo Pull origin, clique nele.

Isso baixa todas as alterações que outras pessoas fizeram.

--------------------------------------------------------------------------------------------------------------

O Ciclo Diário:
Atualizar (Pull): Siga a Regra de Ouro acima.

Trabalhar (Work): Abra o projeto no RPG Maker, crie seus mapas, personagens, eventos e salve normalmente no editor.

Salvar a Versão (Commit): Quando terminar uma tarefa (mesmo que pequena), volte ao GitHub Desktop.

O programa mostrará todos os arquivos que você alterou.

Na caixa "Summary" no canto inferior esquerdo, escreva um resumo claro e curto do que você fez.

"Criei o NPC da biblioteca e seus diálogos"

Clique no botão azul Commit to main.

Enviar para a Nuvem (Push): Após o "commit", clique no botão Push origin no topo. Isso envia suas alterações para o GitHub, para que todos possam baixar.

O ciclo é: Pull -> Trabalhar -> Commit -> Push.
